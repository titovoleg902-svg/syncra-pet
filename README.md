# Syncra PET

Семейный трекер ухода за собакой: Telegram-бот и Mini App (по ТЗ «Syncra PET — MVP v1.01»).

## Из чего состоит

```
syncra-pet/
├── bot/        Telegram-бот (Node.js + TypeScript, библиотека grammY)
├── webapp/     Mini App (React + TypeScript, сборка Vite)
├── .env        секреты: токен бота и адрес Mini App (не попадает в git)
└── .env.example  образец .env
```

- **Бот** отвечает на `/start` приветствием и кнопкой «Открыть приложение», ставит постоянную кнопку меню в чате.
- **Mini App** — веб-страница, которую Telegram открывает внутри себя. Telegram требует адрес **https://**,
  поэтому для теста на телефоне локальный сервер «выводится» в интернет через туннель.

## План реализации

| Этап | Что делаем |
|---|---|
| **1 (готов)** | Бот: `/start`, кнопка «Открыть приложение». Экран «Сегодня»: демо-собака с настроением, задачи с отметкой, серия семьи, стиль с закрытыми «Трюками», светлая и тёмная темы |
| 2 | Сервер и база (Supabase/PostgreSQL), проверка входа через Telegram, семья, собаки, общий список задач |
| 3 | Вкладка «Задачи»: создание, повторы, ответственные, история; кнопка «+» |
| 4 | Напоминания от бота с кнопками «Выполнено / Перенести / Открыть задачу», тихие часы |
| 5 | Серия семьи и экран «Регулярность», очки и награды по правилам ТЗ |
| 6 | Вкладка «Питомец»: профиль, генерация персонажа по фото, вещи и эмоции |
| 7 | Приглашения, роли; голосовой ввод; карта; приёмка по чек-листу ТЗ |

## Запуск и проверка на телефоне

### Шаг 1. Установите Node.js (один раз)

Скачайте **LTS-версию** с https://nodejs.org → откройте `.pkg` → «Продолжить» до конца.
Проверка в Терминале: `node -v` должно показать `v20` или новее.

### Шаг 2. Туннель для https

Ничего ставить не нужно: используется бесплатный сервис serveo.net через встроенную в macOS программу `ssh`.
(cloudflared в этой сети заблокирован, localhost.run слишком сильно режет скорость.)
При первом открытии serveo показывает страницу-предупреждение — нажмите кнопку продолжения один раз.

### Шаг 3. Запустите Mini App (Терминал №1)

```bash
cd ~/"Desktop/AI Basis - Influence Strategy/syncra-pet"
npm install        # только в первый раз
npm run phone      # собранная версия — быстро грузится на телефоне
# npm run dev:web  # режим разработки — только для компьютера
```

Откройте http://localhost:5173 в браузере на компьютере — экран «Сегодня» должен появиться.

### Шаг 4. Запустите туннель (Терминал №2)

```bash
cd ~/"Desktop/AI Basis - Influence Strategy/syncra-pet"
npm run tunnel
```

В выводе найдите строку вида `https://xxxxxxxx.serveousercontent.com` и скопируйте её.
Вставьте в файл `.env`:

```
WEBAPP_URL=https://xxxxxxxx.serveousercontent.com
```

> Адрес меняется при каждом перезапуске туннеля (и иногда сам по себе). Тогда обновите `WEBAPP_URL` и перезапустите бота.

### Шаг 5. Запустите бота (Терминал №3)

```bash
cd ~/"Desktop/AI Basis - Influence Strategy/syncra-pet"
npm run dev:bot
```

Должно появиться `✅ Бот @... запущен.`

### Шаг 6. Проверка на телефоне

1. Откройте в Telegram своего бота и отправьте `/start`.
2. Проверьте: пришло приветствие с кнопкой «Открыть приложение», а слева от поля ввода — кнопка меню «Открыть приложение».
3. Откройте приложение. Проверьте:
   - собака «дышит» и покачивается, раз в 8–12 секунд наклоняет голову;
   - отметка задачи → галочка, вибрация, собака подпрыгивает и «Радуется» 30 минут;
   - повторное нажатие снимает отметку (задача снова в работе);
   - прошедшие неотмеченные задачи — «Просрочено», собака «Скучает»;
   - «Серия семьи» показывает «Сегодня N из 3 задач»; после 3 отметок цель закрыта, серия +1;
   - вкладка «Трюки» с замком, по нажатию — «В разработке»;
   - кружки семьи вверху → «Семья и настройки» → тема «Как в Telegram / Светлая / Тёмная»;
   - в режиме «Как в Telegram» смените тему Telegram — приложение перекрасится без перезапуска.
4. После правок кода остановите `npm run phone` (Ctrl+C), запустите снова и переоткройте Mini App.

## Частые проблемы

| Что видно | Что сделать |
|---|---|
| `Не задан BOT_TOKEN` / `WEBAPP_URL` | Заполните `.env` (шаги 4–5) |
| `Telegram не принял BOT_TOKEN` | Скопируйте токен в @BotFather заново (`/mybots` → бот → API Token) |
| Mini App не открывается / пустой экран | Проверьте, что терминалы №1 и №2 работают и адрес в `.env` совпадает с туннелем; перезапустите бота |
| `command not found: npm` | Не установлен Node.js — шаг 1 |

## Где что лежит в коде

- `bot/src/index.ts` — команды бота и кнопки
- `bot/src/config.ts` — чтение `.env`
- `webapp/src/App.tsx` — экран «Сегодня», нижнее меню, настройки
- `webapp/src/demo.ts` — демо-данные и правила ТЗ (цель дня 3, радость 30 мин, очки)
- `webapp/src/theme.ts` — темы
- `webapp/src/styles.css` — оформление и палитры
- `webapp/src/assets/pet/` — три состояния демо-собаки (вырезаны из макетов ТЗ)
